# 00.4 High-Level Design (HLD) — AdhiEMB Enterprise Guide

The application isolates concerns across 5 architectural tiers:
1. Presentation Layer (React SPA)
2. Security & Gateway Layer (JwtAuthenticationFilter, CORS)
3. Application Service Layer (@Service, @Transactional, AuditAspect)
4. Persistence Layer (Spring Data JPA)
5. Database Layer (MySQL 8.0)
