# 00.3 System Architecture — AdhiEMB Enterprise Guide

AdhiEMB is built on a decoupled API-first client-server architecture:
- **Frontend**: React 18, TypeScript, Vite, TailwindCSS (Port 5173).
- **Backend**: Spring Boot 3.3.2, Spring Security 6.3, Spring Data JPA, Flyway 10 (Port 8080).
- **Database**: MySQL 8.0 (`adhiemb_db`).
