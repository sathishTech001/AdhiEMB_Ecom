# 00.1 Project Introduction — AdhiEMB Enterprise Guide

AdhiEMB is an enterprise digital marketplace dedicated to multi-format machine embroidery design files (.DST, .PES, .EXP, .JEF, .VP3, .XXX, .EMB).

## Core Capabilities
1. Multitenant role governance (Owner, Admin, Employee, Designer, Customer).
2. Designer submission and approval workflow.
3. Multilevel category structures and multi-filter product search.
4. Instant payment verification and zero-trust time-limited download token streaming.
5. AOP-backed immutable audit logs and real-time user notification feeds.
